# 机械臂模型适配（仿真）

控制器通过 MuJoCo 的雅可比和实际关节状态适配不同型号；它不依赖固定的 6 轴或 7 轴。项目自带 `robot_models/ur5e/profile.json` 和 `robot_models/panda/profile.json`，分别对应其目录内的 `model.xml`。配置、MJCF 和所有引用的网格/纹理要一起复制。网页显示的是关节点示意图，不是模型的真实网格。

## 新型号的步骤

1. 准备能由 MuJoCo 加载的固定基座 MJCF 模型及全部资产。URDF 可作为建模起点，但通常还需补齐资产、关节限位、位置执行器、TCP site 和初始 keyframe；不能保证任意 URDF 直接工作。服务端控制周期和物理步长的要求以服务端实现为准。模型必须能稳定独立步进。
2. 在 `robot_models` 下创建型号目录，将模型及资产放入。复制已有 `profile.json`，逐项修改。`model` 是相对于配置文件的 XML 路径；`tcp` 是末端 `site` 名；`home_key` 是安全的初始 `keyframe` 名。`joints` 必须从基座到末端列出该链所有运动关节，`actuators` 同顺序一一对应。每个关节必须是有限位置范围的 hinge/slide，执行器必须是直接驱动该关节、单位齿轮比、带控制范围的 MuJoCo 位置伺服；不能将力矩执行器直接当位置伺服使用。控制范围和关节范围取交集。
3. `velocity` 和 `acceleration` 按关节顺序填写正数。转动关节单位分别是 rad/s 和 rad/s²，滑动关节为 m/s 和 m/s²。这些是控制器参考限值，不能保证动力学的实际速度和加速度满足它们。应依据模型、任务与验证谨慎设定；示例参数仅供仿真实验。
4. 若有夹爪，`gripper.joints` 和 `bodies` 一一对应；`closed` 与 `open` 是每个夹爪关节关闭和打开时的坐标，允许两者方向相反。`actuators` 列出夹爪执行器，`control_closed` 和 `control_open` 是各执行器两端控制值，允许肌腱驱动和反向开合。无夹爪时省略 `gripper`。使用独立的物理测试确认开合方向、范围和稳定性。
5. 先以低速在仿真中逐轴测试平移、转动、夹爪、极限附近和松手保持，检查雅可比有限差分及执行器受力。模型尺寸、关节数量、奇异位形、负载和位置伺服参数会影响可达性和跟踪表现；同一套控制器不保证所有型号都完成任意位姿。此项目没有实机驱动、避障或实机安全验证。

后端会自动发现含 `profile.json` 的型号目录，网页的机械臂下拉菜单会列出这些目录；也可用 `MujocoBackend('型号目录名')` 或 `MujocoBackend('自定义名称', profile_path='配置文件路径')` 加载。模型物理步长必须能整除 0.01 秒控制周期。加载时会检查名称、TCP 链、执行器类型及范围、限值和初始位置；这不是模型正确性或运动安全的全面验证。新增目录之后刷新网页；若切换失败，检查模型文件及配置。
