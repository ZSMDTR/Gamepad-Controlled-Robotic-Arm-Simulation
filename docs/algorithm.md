# 第一版控制算法

## 1. 位置任务

使用固定在末端连杆上的 TCP。当前关节角为 q，位置 p=f(q)，位置雅可比为 J。手柄输入只指定 XYZ 速度，不指定朝向。

目标更新为 `p_target += 0.12 * direction * dt`，并将 `p_target - p` 的模限制为 0.06 m。误差乘以 `min(1, 8*dt)` 后作为当周期位置增量，避免每次试图消除所有积累误差。

这里使用目标位置持续闭环更新，而不是一次求出整条完整轨迹。

## 2. 两种求解器

设 `J = U diag(s) Vᵀ`，`alpha = Uᵀ e`。

### DLS 基线

`dq = V diag(s / (s² + lambda²)) alpha`，默认 lambda=0.04 m/rad。

### SDLS

本实现限定一个三维 TCP、全部为旋转关节。依照论文公式 (3)(4) 独立实现：

```text
rho_j = norm(J[:, j])
对每个有效奇异方向 i：
    N_i = norm(U[:, i])
    M_i = sum(abs(V[j, i]) * rho_j) / s_i
    gamma_i = gamma_max * min(1, N_i / M_i)
    contribution_i = ClampMaxAbs(V[:, i] * alpha_i / s_i, gamma_i)
dq = ClampMaxAbs(sum(contribution_i), gamma_max)
```

`ClampMaxAbs` 按统一比例缩小整个向量，限制最大绝对分量，不是每个分量独立裁剪。默认 gamma_max=0.2 rad，是数值求解步长上限；随后还会用真实周期限制速度与加速度，因此它不等于最终每周期允许转动 0.2 rad。

小于 `max(1e-10, max(s)*1e-8)` 的奇异值截断。固定目标距离限幅、该阈值、控制增益与后续约束是本原型的工程选择，不属于论文实验的完整复刻。作者可下载的 2004 C++ 示例用了不同的平滑缩放，本项目遵循论文中的硬限幅公式。

## 3. 肘部姿态偏好

从数值有效秩的右奇异向量构造 `N = I - V_r V_rᵀ`，而不是用带阻尼的伪逆构造所谓“精确零空间”。将靠近初始关节角的梯度投影到 N 中，对肩/肘关节赋予较高权重。

总期望速度：`qdot_desired = dq/dt + elbow_weight * N * posture_gradient`。

在数值秩的精度范围内，`J @ N` 接近零。有限步长、雅可比变化和后续裁剪仍可能产生末端偏差。六关节、三个位置任务在 J 满行秩时有三维局部冗余，但不能据此保证肘部任意移动。

## 4. 约束与暂停

连续输入先限制关节速度到 0.8 rad/s，并用靠近关节限位的制动包络减速，然后限制相邻速度变化到 2.5 rad/s²。最终仍有硬关节限位。

松开使能或输入回零时，仿真立即冻结 q、清零速度、把目标设为当前 TCP。这一操作以及最终硬限位可能打断加速度连续性；真实硬件应由独立的可行制动轨迹接管。

后端以固定仿真 dt=0.01 s 调度。指令 250 ms 未更新即停用；系统暂停后不回放积压控制步。运行过慢时仿真时间会落后墙钟时间。HTTP 输入和界面刷新频率不决定求解器 dt。

## 5. 需要进一步解决的事项

- 模型与实物的零点、连杆、TCP、轴向、时延和关节约束校准。
- 让肘部目标显式可控：用肘部几何代价或任务优先级 QP 替代当前初始姿态偏好。
- 将位置、速度、加速度与碰撞约束统一放入 QP，而不是求解后分别裁剪。
- 接入动力学仿真并验证接触/碰撞；当前界面只展示运动学。
- 实测手柄到TCP响应延迟；NumPy 计算耗时不能代表整个系统。
