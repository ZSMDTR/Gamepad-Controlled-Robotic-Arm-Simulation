# 第一版验证记录

验证日期：2026-10-26。该记录只覆盖通用六关节运动学模型。

## 自动化验证

运行 `python -m unittest discover -s tests -v`，共 13 项测试通过：

- 解析雅可比与中心有限差分一致；关节旋转保持连杆长度。
- DLS 与独立手算例子一致。
- SDLS 对角模型的分方向限幅结果正确；秩亏时输出有限且有界。
- 数值零空间满足 `J N ≈ 0`、`N² ≈ N`。
- 两种算法在持续远离/反向输入下满足目标超前、关节位置、速度及连续运动加速度约束。
- 松手/回中冻结、非法数值不污染状态。
- HTTP 超时、参数校验、复位、静态资源与跨站控制拒绝。

## 单次计算基准

命令：`python scripts/benchmark.py --steps 2000 --json`。NumPy 2.3.5，本机 Linux。各方法先预热 100 步、复位后使用相同确定性输入；一个串行进程内先 DLS 后 SDLS。

| 方法 | 平均耗时 ms | p99 ms | 最大 ms | 受限目标 RMS 误差 mm |
| --- | ---: | ---: | ---: | ---: |
| DLS | 0.132 | 0.273 | 3.526 | 10.072 |
| SDLS | 0.148 | 0.166 | 0.192 | 9.355 |

两者本次目标超前限幅触发次数均为 0。此表是**单次观测**，不是统计性能结论。系统负载、顺序、BLAS 和硬件都会影响尾延迟；不要据此认定某算法总是更快。

时间包含 `Controller.step()` 的数值计算与状态输出，不包含 HTTP、浏览器、Gamepad API、视频显示及真实执行器。误差参照可能被限幅的目标，不代表无约束手柄轨迹跟踪能力。
